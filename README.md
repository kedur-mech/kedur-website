# Kedur website

Source for **https://kedur.co.uk** — a Jekyll site hosted free on GitHub Pages.

## Editing content
- **Services:** edit `_data/services.yml`
- **Home page text:** edit `index.html`
- **Email, title, description:** edit `_config.yml`
- **Colours and fonts:** edit `assets/css/style.css`

Commit the change on GitHub and the site rebuilds automatically within a minute or two.

## Do not delete
- `CNAME` — tells GitHub Pages to serve the site on kedur.co.uk.
